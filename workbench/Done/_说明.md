# Done —— 已完成

## 收什么

真正做完的任务卡。

**这里是缓冲区，不是成就墙。**

## 每周清一次（硬性）

对每张卡按顺序问三个问题：

1. **产出物在哪？** 应该已经在 `repo` 字段指向的仓库里。如果产出只存在于这张卡里 → 先搬进仓库，再删卡。
2. **有没有可复用的结论？** 有 → 写进 `../../knowledge-base/10-Knowledge/`，然后删卡。
3. **要不要留痕？** 只有「以后会回头看」的才留（比如一份决策依据），否则删。

**默认动作是删除。** 卡片本身没有价值，卡片指向的东西才有。

## 为什么这么定

`Done/` 无限膨胀 = 三个月后再也没人打开它，变成垃圾堆。

这条规则是「定期捞回、无价值删除」原则的落点。
