# Next —— 排队待做

## 收什么

已经**决定要做**、但还没开始的任务卡。

判断标准：**如果现在有空，你会立刻开始做它。** 不是的话，放 `../Later/`。

## 不收什么

| 内容 | 该去哪 |
| --- | --- |
| 已经在做 | `../Now/` |
| 「有意思但没承诺」 | `../Later/` |
| 还没判定性质的杂事 | `../../knowledge-base/00-Inbox/` 先放 |

## 排序

用文件名序号表达优先级：`01-`、`02-`……

序号是**相对顺序**，不是截止日期。日期写 frontmatter 的 `due`。

## 出口

- 开始做 → `../Now/`
- 三周内没动过 → 降级 `../Later/`
