# Cancelled —— 已放弃

## 收什么

明确决定**不做**的任务卡。

**必须写清为什么放弃**，否则不许放这里 —— 直接删。

## 格式

在卡片末尾补一段：

```markdown
## 为什么放弃

（当时的判断依据 / 被什么替代了 / 什么条件下会重新考虑）
```

## 每季度清一次

- 判断依据**仍然有效**的 → 保留。它是一份决策记录，避免以后重复踩同一个坑。
- 已经**过时**的（前提变了、被别的事覆盖了）→ 删除。

## 与 Later/ 的区别

| 目录 | 含义 |
| --- | --- |
| `../Later/` | 还没决定做不做 |
| 这里 | 已经决定不做，且记下了原因 |
