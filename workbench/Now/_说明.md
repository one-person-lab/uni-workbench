# Now —— 正在做

## 收什么

已经**动手在做**的任务卡。

## 不收什么

| 内容 | 该去哪 |
| --- | --- |
| 还没开始 | `../Next/` |
| 「想做但没承诺」 | `../Later/` |
| 项目本身 | `../../knowledge-base/20-Projects/`（这里只放"这个项目当下要做的那一件事"） |
| 知识 / 资料 / 想法 | `../../knowledge-base/` 对应层 |

## 硬规则

- **WIP 上限 1–3 件。** 超过 3 件说明没有在做取舍，先关掉一件再新增。
- 每张卡必须能回答「下一步是什么」。答不上来 → 退回 `../Later/`。
- 这里的卡一旦停手超过一周，降级回 `../Next/`，并写一句为什么停。

## 出口

- 做完了 → `../Done/`
- 决定不做了 → `../Cancelled/`（必须写原因）
- 暂时做不动 → `../Next/` 或 `../Later/`
