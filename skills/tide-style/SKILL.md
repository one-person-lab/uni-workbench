# 潮汐式沉浸设计规范（Tide-style）

## 风格内核

**界面是一扇窗，窗外是自然。**

一句话记住：潮汐风是"收进来"的设计——不是向用户喊话，是给用户一个可以待着的空间。它用自然场景 + 玻璃 + 微光制造安静与信任："这里很稳，你可以慢慢来。"

四条不可妥协的特征：

1. **沉浸底** —— 页面有"场景感"：要么全屏自然摄影/氛围图，要么夜色极光渐变（`--bg-app`）。内容浮在场景上，**绝不浮在纯白/纯灰纸面上**。
2. **玻璃面板** —— 半透明白 surface + `backdrop-filter: blur(20px)` + 1px 白色高光描边 + 内高光。卡片是"结在场景上的露水"，不是贴上去的纸片。
3. **冷底暖点** —— 底色是深蓝夜色系（冷、静），唯一的暖色是品牌金（`#f4c77c` 系），**只给主 CTA、进度、高亮**。暖色是黑暗里的灯，铺开就废了。
4. **柔与慢** —— 大圆角（14–26px）与胶囊、多层柔和阴影、动效 300–400ms、呼吸/漂浮微动效。急促、生硬、跳变都是风格事故。

**一出现就毁掉风格的东西**（反面清单）：
高饱和撞色 · 粗黑描边 · 硬投影（blur=0）· 小圆角（<10px）· 纯白实心卡直贴深底 · 每页换一套底色/底图 · 低对比灰字灰底（深底上的次要文字透明度不得低于 0.42）· 时长 <150ms 的跳变 · 信息密度过载（一屏超过 1 个主焦点 + 2 个次焦点）· 与场景无关的装饰性插画

## 何时使用

**触发场景**：助眠 / 专注 / 冥想 / 习惯打卡 / 情绪记录 / 身份养成类产品；需要"陪伴感、安静、长期主义"调性的页面。

**不适用场景**（先说明再动手，别硬套）：数据密集的后台报表、效率工具、需要扫读的文档列表页。这些场景改为 L2/L3 局部使用，保住可读性与密度。

## 工作流

### 第 1 步：判沉浸强度（必做，不要跳）

读 `references/adaptation.md`，确定这个页面属于哪一档：

| 档位 | 底 | 适用 |
|------|------|------|
| **L1 场景沉浸** | 全屏自然摄影/氛围图 + 渐变遮罩 | 首页、打卡完成时刻、测试结果海报——情绪价值最高的"门面页" |
| **L2 氛围渐变** | 夜色极光渐变（无图） | 挑战列表/详情、钱包、统计——功能主体页的默认档 |
| **L3 素面令牌** | 纯 `--bg-page` + 令牌 | 设置、协议、表单等系统页——安静、无装饰 |

**一致性铁律**：同一个 App 内，L2 的渐变底、圆角、玻璃配方、暖金色**全站只有一套**（本项目即 `common/theme.css`）。页面之间可以换强度，绝不能换配方。"每个页面都不太一样"是这个风格最大的事故。

### 第 2 步：定 token

读 `references/tokens.md`。所有颜色走语义令牌（`--bg-* / --surface-* / --text-* / --brand-* / --accent-* / --state-* / --border-*`），**页面里禁止写死颜色**。深浅双主题同构，只换值不换名。

### 第 3 步：出组件

读 `references/components.md`——玻璃卡片、暖金 CTA、胶囊按钮、FAB、信息标签、状态徽章、悬浮玻璃图标钮的完整配方（含各状态与反例）。

### 第 4 步：上动效

读 `references/motion.md`——呼吸动画（风格灵魂）、按压缩放、入场、弹性曲线、低端机降级。

### 第 5 步：uni-app 落地自检

读 `references/adaptation.md` 末节：rpx 单位、`backdrop-filter` 降级兜底、iconify 远程 SVG 图标色必须跟随主题、全屏底图用 swiper 预加载。

## 与 neo-brutalism 的关系

两套 skill 是**互斥的调性，按产品选用**：潮汐风"收进来"（陪伴、安静、信任），neo-brutalism"喊出来"（冲击、确定性、个性）。同一个产品只选一套做主风格；个别"硬承诺"元素（支付确认、契约卡片）如需借用 neo 强度，必须独立成块，不和玻璃组件混排。

## 项目落地（app-client）

- 令牌唯一来源：`common/theme.css`（`page` = 深色默认，`.theme-light` = 浅色）
- 主题机制：`utils/theme.js` + 全局 mixin 注入 `themeClass`，页面根节点必须绑定 `:class="themeClass"`
- 图标：Solar 系（iconify 远程 SVG），`https://api.iconify.design/solar/<name>.svg?color=<动态色>`
- 已知债（收敛中）：页面级硬编码 rgba、首页摄影底图未接令牌、`uni.scss` 遗留默认值——新页面一律直接走本规范，不复制旧写法

## 文件清单

- `references/components.md` —— 玻璃组件配方
