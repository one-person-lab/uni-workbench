# Adaptation —— 沉浸强度分级与落地限制

## 强度分级（按页面情绪价值分配，不是按喜好）

| 档位 | 底 | 适用页面 | 情绪 |
|------|------|------|------|
| **L1 场景沉浸** | 全屏自然摄影图（swiper 多场景可切换）+ 底部渐变遮罩 | 首页、打卡完成时刻、身份测试结果/海报页 | "开阔、静、我在自然里" |
| **L2 氛围渐变**（默认档） | `--bg-app` 极光渐变（无图） | 挑战列表/详情、选金、钱包、统计、个人主页 | "夜色里的工作台，稳" |
| **L3 素面令牌** | `--bg-page` 纯色 + 令牌，无光晕装饰 | 设置、协议、表单、webview | "安静，别打扰我操作" |

分配原则：
- **门面页和"时刻页"才配 L1**。摄影底图成本高（包体/流量），且情绪冲击强，铺开就贬值。
- 功能主体页默认 L2。**同一个 App 里 L2 的配方全站唯一**（即 `--bg-app`），不同页面换渐变色相 = 不专业。
- L3 是逃生舱：操作密集页不加装饰，但令牌体系不变。

## L1 底图选材规则（潮汐的选图逻辑）

- 自然景观：水（海/湖/雨）、山、林、田野、雪原——**有人烟痕迹但无人物**（一叶小船、远处灯火），传达"独处但不孤独"
- 竖构图 853×1844 级（9:19.5），webp 格式，单张 ≤400KB，远程托管
- 画面必须有"呼吸区"：上 1/3 和下 1/3 相对空旷，给文字和控件留位置
- 冷调为主，允许暖光源（夕阳/灯光）与品牌金呼应
- **禁**：人物特写、城市街景、抽象 3D 渲染、AI 味插画

## 一致性自检（交付前过一遍）

- [ ] 本页属于 L1/L2/L3 哪档？底是否与该档一致（没有自创渐变）？
- [ ] 所有颜色走令牌？grep 无裸 `#hex` / `rgba(`（L1 白字遮罩除外）
- [ ] 圆角体系内？卡片 26–52rpx、控件胶囊、无 <20rpx 方角
- [ ] 暖金一屏一处？CTA 用 `--text-on-brand`？
- [ ] 动效曲线/时长在 motion.md 规范内？无 <150ms 跳变？
- [ ] 深浅主题都成立（图标动态色、遮罩、玻璃）？
- [ ] 不支持 blur 时页面依然可读？

## uni-app 落地限制（踩过的坑）

1. **rpx 单位**：750 设计稿基准，1rpx≈0.5px@375。阴影/边框用 rpx，text-shadow 用 px（混用会糊）。
2. **backdrop-filter**：App 端 webview 支持，但同屏 ≤4 个 blur 元素；必须先写半透明纯色兜底再写 blur（见 motion.md）。
3. **远程 SVG 图标色**：iconify URL 里 `#` 写 `%23`，颜色按主题动态拼 URL，禁止写死 `%23A8C9C1` 这类裸色。
4. **全屏底图**：fixed 容器 + swiper 承载多场景，`object-fit: cover`；文字区压 `bottom-gradient` 遮罩。
5. **状态栏**：深浅主题切换时状态栏前景色由主题管理器统一同步，页面不自己设。
6. **安全区**：底部留 `env(safe-area-inset-bottom)`，悬浮 TabBar 下内容 padding 加 184rpx 级缓冲。
7. **主题绑定**：页面根节点必须 `:class="themeClass"`（全局 mixin 注入），忘绑 = 浅色主题下页面失效。

## 与其他风格 skill 的边界

- 主风格互斥：本规范（收）vs neo-brutalism（放），同一产品只选一套
- 借用规则：潮汐风产品里出现"契约/承诺"卡（如挑战金支付确认）需要强度时，加的是**内容强度**（大字、数字、留白），不是 neo 的粗边硬投影——玻璃语法不破
