# Tokens —— 语义令牌表

> 唯一来源原则：颜色只在主题文件里定义（项目落地为 `common/theme.css`），业务页面只引用 `var(--xxx)`。
> 深浅双主题同构：令牌名完全一致，只换值。**新增令牌必须两套主题同时加。**

### `--bg-app` 极光渐变配方（L2 页面的底）

深色：
```css
--bg-app: radial-gradient(circle at 50% 0%, rgba(255,226,176,0.12), transparent 18%),
          radial-gradient(circle at 18% 18%, rgba(139,226,213,0.05), transparent 22%),
          linear-gradient(180deg, #101927 0%, #16253a 52%, #1b3047 100%);
```
浅色：
```css
--bg-app: radial-gradient(circle at 50% 0%, rgba(244,199,124,0.2), transparent 20%),
          radial-gradient(circle at 18% 18%, rgba(58,157,145,0.1), transparent 24%),
          linear-gradient(180deg, #f4f7fa 0%, #e7eef5 52%, #dce6f0 100%);
```

配方逻辑（换色相时保持结构）：**顶部一盏暖光（brand 12–20%）+ 左上一缕冷光（accent 5–10%）+ 竖向 3 段夜色渐变**。暖光永远在顶部——"光从上面来"。

## 图标色（iconify 远程 SVG 专项）

远程 SVG 的颜色在 URL 参数里，**必须动态计算，禁止写死**：

```vue
computed: {
  iconColor() {
    return this.themeClass === 'theme-light' ? '%23162033' : '%23f4f7fb'
  }
}
```

要点：URL 里的 `#` 要写成 `%23`；颜色值从对应主题的令牌值换算；一张图两个主题两个色，换主题必须换 URL。

## 反面清单（token 层）

- ❌ 页面里写 `#1c2d44`、`rgba(255,255,255,0.08)` 这类裸值（应引用令牌）
- ❌ `uni.scss` 等第二处令牌源另起炉灶（本项目遗留 `#121212` 与 `--bg-page` 冲突，收敛中）
- ❌ 同一组件给深浅主题各写一套选择器覆盖（应只依赖令牌自动切换）
- ❌ 深浅主题之间令牌名对不上（加了深色的忘了浅色）
