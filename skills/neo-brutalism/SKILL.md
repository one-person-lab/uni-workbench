# Neo-Brutalism 设计规范

## 风格内核

**把界面当成印刷品，不是玻璃。**

一句话记住：neo-brutalism 是"喊出来"的设计。它用物理感和高对比制造确定性——"这个按钮就是能按，这事就是真的"。

四条不可妥协的特征：

1. **粗描边** —— 2–4px 实心黑边（或深墨色如 `#1C293C`），不用 0.5px 浅灰细线
2. **硬投影** —— `box-shadow: 4px 4px 0 #000`，**模糊半径必须为 0**，绝不用柔和阴影
3. **钝角** —— 圆角 0（首选）到 4px，绝不用 8px 以上或胶囊形
4. **高饱和撞色** —— 1–2 个高纯度主色 + 极浅底 + 纯黑文字，不用莫兰迪色与低饱和灰调

**一出现就毁掉风格的东西**（反面清单）：
渐变 · 玻璃拟态 / 毛玻璃 / backdrop-blur · 柔和阴影 · 8px 以上圆角 · 胶囊按钮 · 低饱和灰调 · 过渡时长 > 150ms · 半透明遮罩叠色 · 字重 < 400 · 装饰性插画

## 何时使用

**触发场景**：用户明确要求 neo-brutalism / 粗野主义 / 粗粝风格；或要求"高视觉冲击力""不要 AI 味""要有个性"；或需要让界面"显得具体、可信、有分量"——尤其支付、承诺、数据类场景。

**不适用场景**（先说明再动手，别硬套）：医疗、政务、金融理财等需要权威稳重感的场景；面向老年用户的产品；以"柔和陪伴"为调性的产品。这类情况不要全站套用，改为 L1/L2 局部使用。

## 工作流

### 第 1 步：先判适配与强度（必做，不要跳）

读 `references/adaptation.md`，确定三件事：这个产品/页面**该不该**用、用哪一档**强度**、哪些元素**必须留在**原风格。

**强度分档：**

| 档位 | 范围 | 适用 |
|------|------|------|
| **L3 全量** | 整个产品换皮 | 本身就要"喊"的产品：潮牌、独立创作者平台、游戏化产品、活动落地页、年轻向工具 |
| **L2 局部**（默认推荐） | 只用在"硬承诺"元素：主 CTA、提交/支付按钮、卡券、打卡、成就徽章、警示条、空状态 | 调性偏柔和但需要视觉锚点的产品。**大多数产品的最佳答案** |
| **L1 点缀** | 单个元素：一个主按钮，或一组徽章 | 只想加记忆点、不改整体调性的产品 |

L1/L2 场景下，风格元素必须自成一体。不要把一个 3px 黑边卡片塞进一堆 0.5px 细线卡片里还指望它协调——要么给它明确的"重量级"语义，要么连邻居一起改。

### 第 2 步：定 token

读 `references/tokens.md` 取配色与字体方案。内置三套配色：

- **经典黄紫**（`#FDC800` + `#432DD7`）—— 通用、明亮、亲和
- **纯黑白**（黑 + 纸白 + 一个荧光点缀）—— 克制、高级，适合工具类
- **警示红黑**（`#DC2626` + 黑）—— 强调风险与紧迫，适合金融 / 警示场景

优先在项目既有的 token 体系（CSS 变量 / Tailwind config / 设计系统）里落地，不要硬编码散落各处。

### 第 3 步：出组件

组装组件时读 `references/components.md`——按钮、卡片、输入、弹窗、进度、徽章、Tab、空状态、表格的完整配方（含各状态与反例）。

涉及图标时读 `references/icons.md`——线宽、端点、图标集选型（推荐 Phosphor Bold）、以及"彩色 emoji 换单色图标后如何补偿颜色区分"。**图标是这套风格最容易翻车的一环**：其他都对了、图标一软，整个界面就泄气。

需要快速起步时直接引用 `assets/neo-brutalism.css`，内含全部 CSS 变量与基础组件类，改两个变量即可接入。

### 第 4 步：按自检清单验收

交付前逐条过 `references/adaptation.md` 末尾的「交付自检清单」。

## 硬性规则

**必须**
- 用 token 表达颜色与间距，不写裸值（一次性宣传页除外）
- 描边、投影、圆角三者全局一致——描边 3px 就都 3px，投影 4px 就都 4px
- 交互态显式定义：hover / focus-visible / active / disabled
- 焦点态用可见的粗描边（如 `outline: 3px solid`），不用细微光晕
- 对比度 ≥ WCAG 2.2 AA（正文 4.5:1，大字号 3:1）
- 字重只用 400 / 500 / 700，标题用 700 制造分量

**禁止**
- 渐变、模糊、透明度叠色
- 胶囊形与 8px 以上圆角
- 柔和阴影（`box-shadow` 模糊值必须为 0）
- 半透明黑色遮罩（用纯色实心遮罩）
- 装饰性动效（弹跳、旋转、粒子）；动效只用于状态反馈，时长 80–150ms

## 排版

- 正文用无衬线（Inter / 系统字体 / 苹方）；**标签与数据用等宽字体**（JetBrains Mono / SF Mono）——这是 neo-brutalism 最容易被忽略、但最提气质的一笔
- 英文标题可全大写 + 加大字距；中文标题不加字距
- 字阶紧凑，不做大跨度跳跃：`13/15/17/21/27/35`
- 数字、金额、编号一律等宽字体，右对齐或定宽

## 与其他风格的区别

- **vs Brutalism（原始粗野主义）**：更原始、更少修饰、常用生锈色与系统默认字体。neo-brutalism 是它商业化、易用化的版本
- **vs Neumorphism（新拟态）**：完全相反。新拟态用双向柔和阴影把元素从背景"挤出"来；neo-brutalism 用实心描边和硬投影把元素"贴"上去
- **vs Bento / Minimal**：那两者靠留白与克制营造高级感；neo-brutalism 靠重量与对比营造存在感
