# 使用帮助

只回答说明，不因用户在帮助请求中的举例启动诊断或其他任务。如果用户明确要求“说明完就处理某件事”，本轮仍只完成帮助，并请用户下一轮提交该任务，以遵守单参考规则。

帮助答复本身要完整、自包含。用户只问用法时，直接给入口、示例与边界，不以“要不要我帮你判断”之类追问收尾。

## 一句话说明

`jianghushuo` 是基于姜胡说公开视频与著作《价值心法》研究提炼的非官方自媒体行动系统。它帮助用户从真实经历出发，完成定位诊断、选题、内容制作、发布复盘和知识资产沉淀。

它不是姜胡说本人、官方产品、数字分身、口吻模仿器或爆款保证器。

## 适用问题

- 想做个人 IP 或 AI 自媒体，但不知道从哪里开始；
- 从真实经历、项目、问题、评论或私信中找选题；
- 把已有素材或选题做成口播、图文或文章；
- 分析播放、收藏、评论、关注、私信、领取、成交和使用反馈；
- 把问题、素材、内容、反馈和方法连成可复用资产；
- 用 AI 采访、追问、找盲点和整理方法，而不是编造个人经历。

## 怎么开始

Claude Code 通常使用斜杠命令：

```text
/jianghushuo
/jianghushuo 新手入门
/jianghushuo help
```

Codex 或支持 `$skill-name` 的 Agent 通常使用：

```text
$jianghushuo
$jianghushuo 新手入门
$jianghushuo help
```

若客户端没有显示命令入口，可直接说：`使用 jianghushuo，帮我处理这件真实任务：...`。具体调用方式以当前客户端为准，不把任一种命令语法宣称为所有 AI 产品通用。

直接附上真实任务即可，例如：

```text
/jianghushuo 我想做 AI 自媒体，但不知道从哪里开始
/jianghushuo 我用 AI 整理了几百条字幕，这件事能讲什么
/jianghushuo 这个选题已经定了，帮我写成能直接拍的口播
/jianghushuo 播放很低，但来了几个认真咨询，帮我复盘
/jianghushuo 我的资料很多，每次做内容还是找不到素材
/jianghushuo 把这次结论沉淀成以后能复用的 SOP
```

系统读取当前对话，每次只处理一个当前任务，不要求用户安装或调用其他子 Skill，也不强制走完整流水线。

## 两种模式

默认轻量模式通常交付：一句判断、一个推荐、可直接使用的内容或动作，以及必要边界。诊断、选题、复盘和实验任务会给观察信号；单纯写稿或改稿不强行附带实验说明。

用户明确要求完整诊断、深度策划、系统复盘、完整知识库、长期资产、SOP 或工作流时使用深度模式。深度模式可能增加事实/推断分类、问题卡、实验、复盘和写回方案。

## 《价值心法》方法来源速查

下面只列本 Skill 实际采用的高度压缩方法，不提供逐章替代性摘要：

- 方向与长期投入判断：转述自代序《我（一个普通人）的奋斗》；
- 先明确目的、完成标准和行动边界：转述自第 12 章《行动的方法》；
- 用一个互补技能增强同一问题的交付：转述自第 13 章《第二技能》；
- 从具体需要、结果和场景判断用户价值：转述自第 11 章《做有价值的事》；创作者与用户问题的交集综合参考第 15 章《影响他人的行为》；
- 用讲解、行动、反馈和重新理解检验掌握程度：转述自第 4 章《阅读与理解》；
- 先完成低阻力输出，并把外部材料连接成自己的判断：转述自第 7 章《每天写点什么》；
- “痛苦/停止清单”作为避免重复伤害信任的复盘规则：综合转述自第 1 章《你自己就可以是一家公司》和第 9 章《做正确的事，正确地做事》；书中相关概念转述自约翰尼·卡森和查理·芒格；
- 先用不预设结果的小片段收集真实反馈：转述自第 16 章《阳谋！》，本项目额外要求不能用单一互动指标判定价值；
- 知识连接、方法卡和研究后重写：综合转述自第 4、6、8、11 章，并由本项目补充证据状态和知识写回结构。

第 17—23 章的股票、估值和投资操作不进入本 Skill。询问某条方法具体来源时，直接给对应章节、转述关系和本项目新增的约束，不复制大段原文。

## 提问方式

- 已提供的信息不重复问；
- 一次只问一个会改变判断的问题；
- 问完要推进到结果，不能无限采访；
- 缺失只影响措辞时，可先给带少量待确认标记的草稿。

## 不会做什么

- 不编造经历、案例、评论、数据或观点；
- 不承诺爆款、涨粉、收入和固定周期；
- 不把历史经验写成永久平台算法；
- 不把传播、理解、信任、交易和交付混成一个指标；
- 不模仿粗口、羞辱或压迫式人格；
- 不代表姜胡说本人发表观点；
- 不提供股票、估值、仓位、买卖点、收益或其他投资建议；《价值心法》第 17—23 章不属于本 Skill 的工作范围；
- 不自动公开、上传、发布或写入用户材料；
- 不强迫用户迁移到某种知识库工具或目录。

## 知识库与隐私

## 纯投资请求的答复
