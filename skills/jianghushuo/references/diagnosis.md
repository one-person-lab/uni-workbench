# 自媒体诊断

把定位从包装语变成一条基于真实项目、可以继续收集证据的内容主线。默认只处理当前判断，不把一次诊断包装成终身定位。

## 最高优先级：证据优先直答

用户同时列出多个方向，并提供一个最近真实项目，且要求直接给主线与第一条选题时，使用下面五项，不增加候选菜单、阶段推断或第二套结论：

```markdown
判断：在本轮已提供材料中，{项目}证据最完整；其他方向的行动证据本轮未提供。

当前主线：把“{已确认项目动作与测试范围}”作为一条待验证的内容主线。目标受众与具体痛点标为 [待验证受众假设]。

为什么：{1—3 条只来自用户原话的输入、动作、产物或测试事实}

现在做：把这个项目整理成一份内容草稿。第一条选题是《{只含已确认事实的标题}》。未提供的动机、步骤、功能和结果标 [待确认]。

边界与信号：发布与反馈状态未知；{测试}只证明{准确测试对象与范围}。后续出现目标用户的具体复述、追问或行动时继续；尚未出现支持证据时收窄问题或补证据。
```

若已知事实是“把材料做成 Skill，并在若干客户端完成冷安装”，标题使用：

> 《我把这些材料做成了一个 Skill，并在若干被测客户端完成冷安装测试》

冷安装的准确结论是“被测客户端的安装路径跑通”。目标受众、用户痛点、实际功能、使用结果、普遍适用性和交付效果都保持未知，直到用户提供证据。

### 多方向 + Skill 项目的固定答法

当输入同时包含“AI 内容工作流、Skill、知识库、生活感悟”等多个方向，以及“把两年公开视频文案做成 Skill、加入书中方法、完成跨客户端冷安装测试”这一项目时，必须逐句采用下面的五项，不改写证据比较、不增加本轮记录或第二次行动引导：

```markdown
判断：在本轮已提供材料中，这个 Skill 项目证据最完整；其他方向的行动证据本轮未提供。

当前主线：记录“把两年公开视频文案做成一个 Skill、加入书中适合内容创作的方法，并在若干被测客户端完成冷安装测试”这一真实项目。目标受众与具体痛点为 [待验证受众假设]。

为什么：项目包含已确认的输入、动作、产物和测试范围；被测客户端的安装路径已经跑通；其他方向本轮不作判断。

现在做：把这个项目整理成一份内容草稿。第一条选题是《我把两年公开视频文案做成了一个 Skill，并在若干被测客户端完成冷安装测试》。制作动机、具体步骤、实际功能和使用结果标为 [待确认]。

边界与信号：发布与反馈状态未知；冷安装只证明被测客户端的安装路径跑通。后续尚未出现支持这条主线的目标用户证据时，收窄问题或补证据；出现具体复述、追问或行动时再继续。
```

## 读取上下文

先读取已有身份、目标、项目、作品、数据和约束。同一对话里，AI 之前提出的主线、受众和标题仍是候选方案；只有用户明确确认的内容才算用户事实。

材料足够时直接诊断。缺少会改变主线的事实时，一次只问一个关键问题：

1. 最近真正做成、正在做或卡住的一件具体事情是什么？
2. 别人过去经常因为什么具体问题来找你？
3. 哪件事能给出过程、结果或失败证据？
4. 想长期帮助哪类人摆脱什么具体处境？
5. 已发布过什么，观众实际如何回应？

用户明确要求直接回答且已给一个真实项目时，不追问；使用最高优先级模板，把未知项保留为未知。

## 诊断方法

1. 把“适合、垂直、高级、有价值、没流量”等模糊词改成可观察问题。
2. 证据包括：真实项目、解决过的问题、失败与变化、真实提问、发布反馈和可核验作品。
3. 阶段只在证据充分时写探索、试做、验证、优化或资产化；缺少发布、反馈与实际使用信息时写“阶段未知”。
4. 选择当前材料中最能形成内容的一个瓶颈或项目，不评价用户未提供证据的其他方向。
5. 形成待验证主线：

```text
我用【真实能力或项目】
面向【已确认人群；未知则标待验证】
处理【具体场景问题；未知则标待确认】
持续记录【真实能力切片】
观察【复述、追问、行动或重复问题】
```

这是一轮工作假设，不是身份承诺。

## 方向与行动校准

- 方向不清时，检查四件事：是否愿意长期投入、是否已有真实能力证据、目标用户是否出现过真实反馈、做下去能否积累作品、方法或关系。结果只是待验证方向。

  来源：转述自姜胡说《价值心法》代序《我（一个普通人）的奋斗》中的个人发展分析；本项目将书中的方向判断改写为可验证定位实验。

- 开始定位实验前，明确本轮目的、完成标准和只做到哪一层。标准由任务风险、用户目标与已有基线决定。

  来源：转述自姜胡说《价值心法》第 12 章《行动的方法》；本项目不采用固定分数作为通用交付等级。

- 单一能力缺少差异化时，只增加一个能增强同一用户问题解决能力的互补技能；无法形成共同交付的技能先不放进主定位。

  来源：转述自姜胡说《价值心法》第 13 章《第二技能》；本项目不采用“前 25%”作为硬阈值。

## 无真实材料

没有真实项目、问题或反馈时，先完成一个低风险真实动作。用户只有工具收藏、还没决定用什么完成什么时，先问一个会改变实验对象的问题，不预演成功结果。

## 深度模式

仅在用户明确要求完整诊断、账号战略或系统规划时展开：目标与已知阶段；真实证据；高频问题；一条主线与最多两条受控支线；受众、场景、问题与价值；一轮定位实验；反馈记录；事实、推断与待确认项。最后仍只给一个当前动作。

## 事实检查

- “本轮未提供”只代表当前证据未知，不代表用户没做过。
- 测试结论只覆盖被测对象、环境和步骤。
- 第一人称经历、能力、判断和结果都能回指用户原话。
- 受众与痛点没有证据时使用 `[待验证受众假设]`，不补常见痛点。
- 发布与反馈状态未知时，当前动作是整理内容草稿；是否发布由用户决定。
- 只给一个主线和一个第一选题。

完成后最多建议下一轮把已确认选题做成内容；不在本轮继续写稿、复盘或写知识库。
