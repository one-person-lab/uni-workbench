# 20-Projects —— 项目索引层（只放卡片，不放内容）

**关键约定：这一层只放「项目索引卡」，不复制项目内容。**

## 为什么这样设计

正在推进的项目，各自的正文都在专属仓库里：

| 项目 | 内容在哪 |
|---|---|
| 媒体工作台 | `one-person-hub/media-hub/` |
| 产品工作台 | `one-person-hub/product-hub/` |
| 职业工作台 | `one-person-hub/career-hub/` |
| 通用工作台 + 知识库 | `one-person-hub/uni-workbench/` |

如果这里再把内容存一份，就是**重复冗余** —— 两边会立刻不同步，且不知道该信哪一份。所以知识库的职责是**指过去**，不是**存下来**。

## 一张索引卡长什么样

每个项目一个 md 文件，内容就三行：

```markdown
# 媒体工作台

一句话：<这个项目在做什么>
仓库：~/workspace/code/one-person-hub/media-hub
状态：进行中
```

## 收什么 / 不收什么

- ✅ 项目清单、一句话定位、仓库路径、当前状态
- ✅ 跨项目的关联（「A 项目产出给 B 项目用」这类关系）
- ❌ 项目正文、方案文档、代码、任务列表 —— 这些留在项目仓库内
