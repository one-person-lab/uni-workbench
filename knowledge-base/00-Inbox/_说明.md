# 00-Inbox —— 无差别入口

**所有东西先扔这里。** 不做分类、不要求格式、不要求完整。看到一句话、一个想法、一篇文章链接，先丢进来。

## 收什么

- 瞬时想法、灵感、待验证的猜测
- 还没来得及读的资料链接
- 项目里冒出来的待办式念头（「这个以后再想」）
- 任何让你犹豫「这该放哪层」的东西 —— 犹豫就放 Inbox

## 不收什么

- 已经能确认归属的东西（直接放对应层，不用在 Inbox 中转）
- 明确要做的具体任务（那是 task 系统的事，不是知识库）

## 出口规则

Inbox 的寿命要短。处理每一条时只有三个去处：

| 判断 | 去向 |
|---|---|
| 我知道了什么、且值得长期留 | → `10-Knowledge/` |
| 是外部材料、需要以后查 | → `30-Resources/` |
| 处理完了、暂时不需要 | → `40-Archive/` |
| 看完发现没价值 | **直接删** |

**判断标准**：如果一条内容在 Inbox 里躺了两周你都没动它，要么归档、要么删 —— 不要让 Inbox 变成第二个 Archive。
