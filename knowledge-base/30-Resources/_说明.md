# 30-Resources —— 外部资料

**别人的东西，我收集来备查或待加工。** 与 `00-Inbox/` 的区别是：Inbox 是「随手碰到的」，这里是我**主动收集并已分类**的外部材料。

## 收什么

- 文章剪藏、书籍／课程笔记（原文性质的，不是我的结论）
- 他人的观点、框架、案例 —— 明确标注是**别人说的**
- 需要长期备查的技术参考、行业资料

## 不收什么

- 我自己消化后的结论 → 那是 `10-Knowledge/`
- 项目文档 → 那是 `20-Projects/` 指向的仓库

## 与 Knowledge 的关系

这里是**原料**，`10-Knowledge/` 是**成品**。加工路径：

```
30-Resources（别人的原文） → 我读懂、用自己的话重写 → 10-Knowledge（我的知识）
```

**不要直接改原文**。要提炼就在 Knowledge 层新建一篇并回链到这里的原文 —— 原文保持原样，方便日后核对我有没有理解偏。

## 命名建议

- `文章-XXX.md`、`书籍-XXX.md`、`资料-XXX.md`
- frontmatter 里尽量记 `source`（原始链接或出处）
